# Data-Science-Assignment-11
# Week 11 – Customer Segmentation & Prediction

## Overview
This project performs customer segmentation using clustering techniques
and builds segment-wise prediction models using Random Forest.

## Dataset
- customer_churn.csv (500 records)

## Methods
- K-Means clustering (Elbow method)
- Hierarchical clustering
- Segment profiling
- Segment-wise Random Forest models
- Evaluation metrics: Accuracy, Precision, Recall, F1

## Segments
- Premium Spenders
- Budget Conscious
- Loyal Long-Term

## Outcome
Segment-specific strategies were derived to improve retention and revenue.
